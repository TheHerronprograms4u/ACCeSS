Undergraduate Paper Accepted at NeurIPS 2024: Efficient Transformer Attention in Edge Devices

BU ACCeSS researchers co-authored a groundbreaking pruning framework reducing sparse attention KV-cache memory footprints by 63% on resource-constrained embedded microcontrollers without degradation in token perplexity.

def sparse_kv_prune(tensor, threshold=0.038):
  return torch.where(tensor.abs() > threshold, tensor, 0.0) # 63.4% VRAM reclaimed
